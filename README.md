# GenAI-Powered Business Insight Engine – Churn Analysis

Overview
This project analyzes customer churn for a SaaS business using real-world style datasets.  
The focus is on generating business insights, not just metrics.

Business Problem
Customer churn impacts revenue and growth.  
This analysis answers:
- How much churn exists?
- Does churn differ by plan tier?
- Which segments are higher risk?

Data Used
- Accounts data: customer, plan, seats, signup info
- Churn events data: churn date, reason, refund, prior changes

Analysis
- Loaded and validated multiple CSV files
- Identified churned vs active accounts
- Compared churn across plan tiers
- Interpreted results from a business perspective

 Tools
Python, pandas, VS Code, GitHub

Key Insight
Lower-tier plans show higher churn, indicating possible value or pricing gaps.
